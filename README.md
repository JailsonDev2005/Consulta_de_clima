🌤️ Consulta de Clima em Python

Projeto desenvolvido exclusivamente para fins de estudo, com o objetivo de praticar o consumo de APIs utilizando Python.

📚 Sobre o projeto

Este programa permite que o usuário digite o nome de uma cidade e receba algumas informações sobre o clima atual.

O projeto utiliza uma API para:

🔎 Encontrar a cidade informada pelo usuário
📍 Obter a latitude e longitude da cidade
🌡️ Consultar a temperatura atual
💧 Consultar a umidade
💨 Consultar a velocidade do vento
🛠️ Tecnologias utilizadas
Python
Requests
API Open-Meteo
JSON

▶️ Como executar
1. Clone o repositório
git clone URL_DO_SEU_REPOSITORIO
2. Entre na pasta do projeto
cd projeto-clima
3. Instale a biblioteca necessária
pip install requests
4. Execute o programa
python main.py

Depois, digite o nome da cidade quando solicitado.

💻 Exemplo
Digite o nome da cidade: Recife

--- Clima ---
Cidade: Recife
Temperatura: 27°C
Umidade: 78%
Vento: 12 km/h
